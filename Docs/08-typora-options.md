# Typora 옵션 대장

[적용 가이드](07-typora.md) · [문서 앱 공유 ID](11-cross-app-options.md#shared) · [Obsidian 대응표](10-obsidian-options.md)

`[x]`는 CSS 생성, `[ ]`는 미구현이다. 원본은 TOML로 조정 가능하고 고정은 CSS만 생성한다. 실제 앱 검증은 따로 기록한다.

## 공통 문서 기능의 Typora 적용

| ID · 설정 대상 | 생성 · 원본/고정/후보 |
|---|---|
| **D01 문서 배경·본문색** | [x] 원본 `background`, `text`. 두 모드에서 본문과 작성 영역 배경을 비교한다. |
| **D02 본문 글꼴 우선순위** | [x] 원본 `typography.prose.families`. EN → KR → JP → 시스템 대체 순서를 보존한다. |
| **D03 본문 크기·줄 높이** | [x] 원본 `typography.prose.size_px`, `line_height`. 한 줄 내부 간격과 문단 사이 간격을 혼동하지 않는다. |
| **D04 코드 글꼴·크기·줄 높이** | [x] 원본 `typography.mono`. 인라인 코드와 코드 블록 모두에 적용한다. |
| **D05 본문 최대 폭·좌우 여백** | [x] [Typora 원본](../themes/editors/typora.toml)의 `[layout]`. 좌우 여백 포함 최대 860px, 좌우 각각 16–32px. 좁은 창에서는 컨테이너를 가용 폭 이내로 줄인다. 표·코드의 넘침은 별도다. 실제 앱 확인은 남아 있다. |
| **D06 문단 앞뒤 간격** | [x] `[paragraph].gap_px`로 최상위 연속 문단 사이 12px. 원문, 줄 높이, 제목·목록과의 간격은 유지한다. |
| **D07 문단 정렬·쓰기 방향** | [x] `[paragraph].alignment = "start"`로 최상위 일반 문단을 시작 쪽에 정렬한다. `"justify"`는 양쪽 정렬, 생략하면 앱 기본값을 유지한다. 쓰기 방향·세로쓰기는 강제하지 않으며 실제 앱의 혼합 문장 편집은 미검증이다. |
| **D08 서체 세부 표현** | 확정 — 기본값 유지. 본문 자간·합자·작은 대문자는 덮어쓰지 않고 제목 대소문자도 변환하지 않는다. 코드의 기존 합자 설정은 별개다. 추가 CSS는 생성하지 않는다. |
| **D09 제목색** | [x] 원본 `heading`을 H1–H6에 연결한다. |
| **D10 제목 단계별 조판** | [x] `[headings.h1]`–`[headings.h6]`로 크기 180/150/130/115/105/100%, 굵기 700/700/600/600/600/600, 단계별 위아래 여백을 지정한다. H1 아래에만 `muted` 색의 1px 구분선을 넣으며 제목색은 유지한다. 실제 앱 화면은 미검증이다. |
| **D11 제목 자동 번호** | 확정 — 테마에서 자동 번호를 생성하지 않는다. 원문에 직접 적은 번호는 그대로 표시하며, 목차·개요 동작은 바꾸지 않는다. |
| **D12 링크색·밑줄** | [x] 색은 원본 `link`, 밑줄은 고정. 밑줄을 끄는 옵션은 없다. |
| **D13 키보드 링크 포커스** | [x] 색은 원본 `focus`, 윤곽선 굵기·거리는 고정. 편집기의 집중 모드와 다르다. |
| **D14 인용문** | [x] 색은 원본 `quote`, 시작 방향 테두리·안쪽 여백은 고정. |
| **D15 인라인 코드색** | [x] 원본 `inline_code`. 별도 배경색이나 테두리 옵션은 없다. |
| **D16 일반 텍스트 선택색** | [x] 본문은 `prose_selection_background`, 코드는 `selection_background`, 선택 글자색은 `selection_text`를 사용한다. |
| **D17 본문 강조 표현** | [x] `[emphasis.light]`·`[emphasis.dark]`로 굵게는 장밋빛, 기울임은 보라색, 취소선은 회색으로 지정하고 각 글자 모양을 유지한다. 형광펜 배경은 라이트 옅은 노랑·다크 짙은 황갈색이다. 일반 본문 배경과 형광펜 배경에서 강조 글자 대비 4.5:1을 검사한다. 코드와 드래그 선택색은 유지하며 실제 앱 화면은 미검증이다. |
| **D18 각주·참조·수평 구분선** | [x] `[footnotes]`와 `[colors]`에서 본문 각주 번호를 청회색(`function` 역할), 각주 글자를 본문의 90% 크기와 `muted` 색으로 지정한다. `[horizontal_rule]`은 Markdown 구분선을 `muted` 색 1px, 위아래 여백 각각 24px로 설정한다. 각주 이동·복귀와 일반 링크는 유지하며, 실제 앱 화면과 내보내기는 미검증이다. |
| **D19 코드 블록 바탕·테두리** | [x] 코드 펜스와 편집 거터는 `code_block_background`, 글자와 테두리는 `text`, `muted`를 사용한다. 모서리·안쪽 여백은 고정이다. |
| **D20 코드 구문색** | [x] 원본 `comment`, `keyword`, `string`, `function`, `number`, `error`. Typora는 `.cm-s-inner`에 연결하지만 Obsidian은 해당 앱의 렌더러에 따로 연결해야 한다. |
| **D21 표** | [x] `[table]` 균형형. 헤더는 `surface` 배경과 굵은 글씨, 셀은 위아래 8px·좌우 12px 여백과 1px 가로선만 적용한다. 화면에서 넓은 표는 표 영역 안에서 가로 스크롤하며, Markdown 열 정렬은 덮어쓰지 않는다. 실제 앱의 표 편집 도구와 내보내기는 미검증이다. |
| **D22 순서·비순서 목록** | [x] `[lists]` 균형형. 단계별 24px 들여쓰기, 연속된 일반 항목에 4px 간격을 적용한다. 비순서 표식은 ● → ○ → ■(3단계 이상), 순서 목록의 시작 번호와 작업 목록의 체크박스·완료 스타일은 유지한다. 실제 앱 화면은 미검증이다. |
| **D23 작업 목록** | [x] `[task_lists]` 균형형. 미완료는 기본 본문색과 빈 체크박스, 완료는 `accent` 체크박스와 완료 항목의 직계 문단에만 `muted` 색과 취소선을 적용한다. `strike_completed = false`로 테마의 취소선을 생략할 수 있다. 하위 항목의 상태와 모양은 유지한다. 실제 앱 화면은 미검증이다. |
| **D24 이미지·캡션** | [x] `[images]` 균형형. 독립 이미지는 본문 폭을 넘지 않도록 가운데에 놓고 확대하지 않는다. 일반 Markdown 독립 이미지의 기존 기본 스타일을 유지하며, 명시적인 이미지 `figcaption`에만 8px 간격·본문의 90% 크기·`muted` 색을 적용한다. 대체 텍스트로 캡션을 만들지 않고, 인라인 이미지와 원본 파일도 변경하지 않는다. 실제 앱 화면은 미검증이다. |
| **D25 수식** | [x] `[math]` 균형형. 독립 수식은 `surface` 배경과 위아래 12px·좌우 16px 안쪽 여백을 쓴다. 새 가로 스크롤 규칙은 화면의 수식 렌더링 영역에만 적용한다. 인라인 수식, 수식 글꼴, 원문은 바꾸지 않는다. 실제 앱 화면과 내보내기는 미검증이다. |
| **D26 알림·콜아웃** | [x] `[alerts]` 균형형. `surface` 배경 위에 NOTE(파랑), TIP(녹색), IMPORTANT(보라), WARNING(황색), CAUTION(붉은색)의 왼쪽 강조선과 제목색을 적용한다. 기본 아이콘·라벨과 일반 인용문을 유지하며 Obsidian에는 적용하지 않는다. 실제 앱 화면은 미검증이다. |

## Typora 전용

- [x] **T01 테마 패키지** — 고정. `lbrx-light.css`, `lbrx-dark.css`, 적용 안내를 생성한다. 앱에 복사하거나 모드를 자동 전환하지 않는다.
- [ ] **T02 집중 모드** — 후보. `--blur-text-color`로 비활성 문단색을 조정하고 활성 문단·링크 가독성을 확인한다. 모드를 켜는 명령은 생성하지 않는다.
- [ ] **T03 라이브 편집 기호** — 후보. 커서가 들어간 강조·링크의 Markdown 기호, 표시 텍스트, URL을 구별한다. 항상 보이기/숨기기는 별도 선택이다.
- [x] **T04 코드 편집기 줄 번호·커서 색** — `muted`, `focus`를 매핑한다. 줄 번호 표시 여부는 변경하지 않는다.
- [ ] **T05 코드 편집 상태** — CodeMirror 코드 펜스 선택 배경은 생성한다. 실제 편집 화면, 활성 줄, 괄호 짝 강조는 미검증 또는 미구현이다.
- [ ] **T06 Markdown 소스 모드** — 후보. 편집 본문과 별도로 글꼴·배경·구문·선택을 확인한다. 코드 펜스용 `.cm-s-inner`는 소스 모드 전체의 구현이 아니다.
- [ ] **T07 문서 내부 `[TOC]`** — 후보. 단계별 들여쓰기·간격·링크·표시 깊이·자동 번호. 본문 제목이나 사이드바 개요를 함께 숨기지 않는다.
- [ ] **T08 사이드바 개요·파일 트리** — 후보, 현재 문서 영역 범위 밖. 활성 항목·계층 표시·개요 번호를 구분한다. 접힘 상태나 파일 순서는 앱에 맡긴다.
- [ ] **T09 YAML 머리말·편집 보조 UI** — 후보, 버전별 선택자 확인 필요. 메타데이터 블록, 검색 결과 강조, 링크 편집 팝업을 본문과 구분한다.
- [ ] **T10 Mermaid 배색·정렬** — 후보. 라이트 `neutral`/다크 `dark`를 시작점으로 노드·연결선·레이블을 확인한다. 문서 내 개별 Mermaid 설정과 충돌하는지 검사한다.
- [ ] **T11 Mermaid 도식별 표현** — 후보. 시퀀스 번호, 흐름도 곡선, 간트 좌측 여백. 번호는 의미를 바꿀 수 있어 기본 강제하지 않는다.
- [ ] **T12 기타 다이어그램** — 후보. `sequence`의 `simple`/`hand`와 `flow` 미리보기를 Mermaid와 별도로 검증한다.
- [x] **T13 다크 환경설정 왼쪽 메뉴 대비** — 메뉴 배경·글자 및 선택·마우스 오버·포커스 색을 생성한다. 문서 탐색 사이드바(T08)와는 별개이며, 실제 앱 화면 검증은 아직 남아 있다.
- [x] **T14 라이트 환경설정 오른쪽 내용 대비** — 오른쪽 패널에 밝은 배경과 어두운 본문·안내문 색을 짝지어 적용하고, 브라우저 기본 입력 컨트롤에는 라이트 색상 체계를 요청한다. 왼쪽 메뉴에는 적용하지 않는다. 실제 앱 화면 검증은 아직 남아 있다.

## 내보내기와 앱 소유 설정

| ID | 옵션 | LBRX 구현 상태·경계 |
|---|---|---|
| X01 | 인쇄·PDF용 밝은 종이색, 텍스트·링크색 | 미구현. 편집 테마와 분리된 인쇄 규칙 또는 내보내기용 테마 후보. |
| X02 | 페이지 나눔, 제목 고립 방지, 표·그림 분할 | 미구현. 두 페이지 이상인 PDF로 실제 확인해야 한다. |
| X03 | HTML 내보내기 테마·목차, 그림 내보내기 폭·글꼴 크기 | 미검증. Typora 내보내기 프로필에서 선택하는 값과 CSS 효과를 분리한다. |
| X04 | PDF 용지 크기·머리말·꼬리말·메타데이터 | 앱 설정. 현재 생성기가 수정하지 않는다. 다크 편집 → 라이트 PDF는 별도 검증한다. |
| X05 | EPUB CSS·표지, DOCX 참조 문서, LaTeX/Pandoc 템플릿 | 별도 배포 형식. 현재 Typora CSS의 지원 대상으로 계산하지 않는다. |
| X06 | 집중·타자기 모드 활성화, 다이어그램 활성화, 단축키, 이미지 저장·업로드 | 앱 동작. 테마가 자동으로 변경하지 않는다. |
