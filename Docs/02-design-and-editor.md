# 팔레트와 편집 경험

WGSN·Coloro의 2026년 색인 [Transformative Teal](https://www.adobe.com/express/learn/blog/color-of-year-trends)에서 **청록 방향만** 가져왔다. 아래 값은 공식 색상 복제가 아닌 자체 시안이다. 글 대부분은 중립색으로 두고, 청록은 링크·포커스·강조처럼 시선이 필요한 곳에 쓴다.

| 역할 / 팔레트 키 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| 배경 / `paper` | `#F3F4EC` | `#19231F` | 옅은 종이색 / 녹색 기운의 차콜 |
| 본문 / `ink` | `#24362F` | `#DCE6DB` | 기본 배경 대비 각각 11.54:1, 12.59:1 |
| 보조 / `muted` | `#52655B` | `#A3B5A9` | 주석·인용. 읽어야 하는 내용은 흐리게 숨기지 않는다. |
| 주 강조 / `pine` | `#246958` | `#84C7AC` | 링크·포커스·문자열 |
| 슬레이트 블루 / `slate` | `#43617B` | `#97BBD6` | 함수·정보 |
| 자두 / `plum` | `#80516A` | `#D4A8BD` | 키워드 |
| 황토 / `ochre` | `#815919` | `#D6B378` | 숫자·경고 |
| 점토 / `clay` | `#A44540` | `#E59E91` | 오류·삭제 |

**읽기 기준:** [WCAG 대비 계산](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)으로 본문/기본 배경은 프로젝트 목표 7:1, 보조 글자·링크·구문 및 선택된 글자/실제 배경은 4.5:1 이상을 요구한다. 포커스 표시는 인접색과 3:1 이상으로 설계한다. 링크 밑줄과 오류 기호도 사용해 색만으로 구분하지 않는다. ANSI 16색은 슬롯의 표준 의미를 유지하며 저대비 조합은 미리보기에서 경고한다. 외부 프로그램이 임의로 고른 모든 전경·배경 쌍의 가독성을 보장하지는 않는다.

**서체 시안:** 본문은 `LINE Seed Sans (EN) → LINE Seed Sans KR → LINE Seed JP_TTF → 시스템 sans-serif`, 16px / 1.65배, 코드는 `D2Coding ligature → 시스템 monospace`, 14px / 1.45배로 시작한다. 본문 목록은 앞의 글꼴이 지원하지 않는 문자를 다음 글꼴에서 찾는 순서이며, 문장 언어를 자동으로 판별해 전환하는 설정은 아니다. 테마는 글꼴 파일을 번들하거나 자동 설치하지 않는다. 목록을 지원하지 않는 앱에는 단일 글꼴과 대안 선택법을 안내한다. 이 값들이 피로를 줄인다고 단정하지 않고 한글 장문, 영문 코드, 숫자 `0O1l`, 혼합 줄바꿈을 실제 화면에서 비교해 조정한다.

**TUI 동선:** `lbrx-theme edit` → 모드 선택 → 팔레트 또는 역할 선택 → 견본 옆에서 RGB/HEX 조절 → 영향받는 역할과 대비 즉시 확인 → 명시적으로 저장. 원래 값과 편집 값을 나란히 표시하고 취소하면 원본을 유지한다. 색상만 나열하지 않고 같은 화면에 한글 문단·Markdown 링크·코드·선택 영역·ANSI 견본을 렌더링한다. 역할 이름과 HEX는 항상 표시한다.

True Color가 아닌 터미널에서는 근사색임을 표시하고, 대비 계산에는 원본 RGB를 사용한다. TUI 자체는 호스트 글꼴과 셀 높이를 바꿀 수 없다. 서체 입력 화면에서는 수치와 대상 앱 지원 여부를 보여주고 실제 조판 확인은 Typora 등 가져온 앱에서 한다.
